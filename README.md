# Minesweeper Game

A Minesweeper game developed in **Java** as part of my **second-year Data Structures module** during my undergraduate studies at North-West University.

The project was created as a practical exercise to apply data structures, algorithms, and Java programming concepts to the development of a functional game.

## About the Project

The game is based on the classic Minesweeper concept. The player interacts with a grid containing hidden mines and must uncover cells while avoiding the mines.

The project focuses on using programming and data structure concepts to manage the game board, mine locations, player actions, and game state.

## Features

* Minesweeper game board
* Different game levels
* Custom game board
* Random mine placement
* Cell revealing
* Mine detection
* Flagging cells
* Display of surrounding mine counts
* Timer
* Win and lose conditions
* Undo functionality
* Sound effects
* Graphical user interface

## How to Run

The project can be compiled and run using Command Prompt.

```cmd
javac MSCell.java
javac SLL.java
javac Minefield.java
javac MinefieldTest.java
java MinefieldTest
```

Alternatively, the included `run.bat` file can be used to compile and run the project.
